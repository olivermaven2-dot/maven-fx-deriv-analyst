# Maven FX Deriv Analyst

Maven FX Deriv Analyst is a browser-based Deriv market analysis tool. It uses live market data to support digit analysis across the Over/Under, Even/Odd, and Rise/Fall engines.

## Scope

- Analysis and signal display only.
- No automated contract purchases or trade execution in the analysis app.
- Keep the analysis stream and engines independent of any separate trading-bot experiments.

## Deployment

The site is published through GitHub Pages from the `main` branch using the workflow in `.github/workflows/pages.yml`.

Live site: https://olivermaven2-dot.github.io/maven-fx-deriv-analyst/
